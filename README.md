# ai-tic-tac-toe · 井字棋人机对战

一个**单个 HTML 文件、零第三方依赖**的井字棋人机对战小游戏。AI 采用经典的 **minimax（极大极小）算法**，并加入 α-β 剪枝；开启"不可战胜"难度后，你最多只能逼平它，永远无法战胜它。

## 功能简介

- **人机对战**：你执子与 AI 对弈，可自选执 **X（先手）** 或 **O（后手）**。
- **两档难度**：
  - **不可战胜**：完整 minimax + α-β 剪枝，理论上不会输（最多平局）。
  - **随机**：AI 随机落子，适合新手练手。
- **计分板**：自动累计「玩家胜 / 平局 / AI 胜」，可一键清空。
- **重新开始**：随时开新局；切换难度或执子方会自动重开。
- **全中文界面**，深色主题，手机与桌面浏览器均可玩。

## 快速开始

无需安装、无需构建、无需联网：

1. 下载 `index.html`；
2. **双击用浏览器打开**即可开始游戏。

也可以本地起一个静态服务预览：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000/index.html
```

## 使用示例

1. 打开页面后默认你执 **X**、AI 执 **O**，你先手；
2. 点击任意空格落子，AI 会自动回应；
3. 想换 AI 强度，在顶部「AI 难度」下拉切换；
4. 想让 AI 先手，把「你执子」选为 **O**；
5. 一局结束后点击「重新开始」，分数保留；点「清空计分」归零。

## minimax 原理通俗讲解

井字棋的局面空间很小（最多 9 步），我们可以把**所有可能的走法全部枚举出来**，画成一棵博弈树。minimax 就是在这棵树上做决策。

### 1. 两个角色：最大化方 vs 最小化方

- **AI（最大化方）**：总是挑对自己**最有利（分数最高）**的走法；
- **玩家（最小化方）**：总是挑对 AI**最不利（分数最低）**的走法。

之所以叫"极大极小"，就是因为双方轮流在「取最大值」和「取最小值」之间切换。

### 2. 给终局打分

递归到棋局结束时给一个分数：

- AI 赢了 → `+10 - 深度`（赢得越快分越高）
- AI 输了 → `-10 + 深度`（输得越晚分越高）
- 平局 → `0`

带上"深度"是为了让 AI **尽快取胜、拖延落败**。

### 3. 自底向上回溯

```
轮到 AI（max）  → 从子局面里挑最高分
轮到玩家（min） → 从子局面里挑最低分
```

AI 在自己这一层会假设：玩家一定走出对 AI 最坏的那步。因此只要存在一种走法让玩家有机会让 AI 输，AI 就会避开它——最终选出**在"玩家全力阻挠"前提下依然能拿到的最好结果**。

### 4. α-β 剪枝（可选优化）

在回溯过程中记录两个边界：

- `alpha`：AI 目前能保证拿到的最好分数（下界）；
- `beta`：玩家目前能把 AI 压到的最差分数（上界）。

如果某个分支已经能让玩家把分数压到比 `alpha` 还低（`beta <= alpha`），那这个分支**不用再算了**——AI 根本不会选它。这样能砍掉大量对称/无用分支，速度更快，但**结果与完整 minimax 完全一致**。

### 5. 为什么"不可战胜"？

因为 minimax 穷举了所有后续局面，并始终假设对手走最优解。只要博弈树里存在"AI 不输"的路径，AI 就一定会选中它。井字棋是一个**确定性、无随机信息的零和博弈**，先手最优下的结局是平局——所以在"不可战胜"难度下，你最多只能和棋，永远赢不了 AI。（想赢？请用"随机"难度。）
